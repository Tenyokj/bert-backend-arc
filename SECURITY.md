# Security Policy

## Testnet Responsible Disclosure

BERT welcomes good-faith reports for this proof-of-personhood backend and its integration with the BERT contracts and frontend.

Submit reports privately through [GitHub Private Security Advisories](https://github.com/Tenyokj/bert-core-arc/security/advisories/new). Do not disclose vulnerabilities, proof payloads, credentials, API secrets, or exploit instructions in public issues.

Include the affected endpoint or module, prerequisites, reproducible steps, expected and actual behavior, impact, and relevant request or transaction references. Do not attempt to access another user's verification data, submit fraudulent proofs, degrade service, or use social engineering.

For a confirmed, previously unknown high-impact report before mainnet launch, BERT may include the researcher's wallet in `initialValidators` when the official BERT Community is deployed. This is not a cash reward or transferable asset; seats are limited and subject to conduct requirements. After launch, new Validator appointments follow the standard on-chain eligibility path.

See the [BERT Testnet Guide](https://bertdao.vercel.app/testnet-information) for full scope and disclosure rules.
